# 100 Days of Machine Learning

Welcome to my **100 Days of Machine Learning** repository! This repository documents my journey of learning and applying various machine learning and deep learning concepts, algorithms, and techniques. The goal is to systematically progress through key topics in machine learning, build projects, and track my learning journey day by day.

## Goal
The aim of this repository is to:
- Learn and implement machine learning models and algorithms
- Work on real-world projects using datasets
- Enhance my understanding of data preprocessing, model evaluation, and feature engineering
- Build a portfolio of projects showcasing different aspects of machine learning

## Current Focus
I am currently working on a variety of machine learning concepts, including supervised and unsupervised learning, deep learning, and real-world data projects. Some areas of focus include:
- Building and evaluating models (e.g., Regression, Decision Trees, SVM, KNN, etc.)
- Data scraping (using tools like BeautifulSoup, Selenium) and analysis of IPL data.
- Deep learning techniques such as neural networks, CNNs, and RNNs.
- Hyperparameter tuning and model optimization.

## Structure
This repository is organized by day, with each day containing:
- **Jupyter Notebooks**: Implementations of various machine learning and deep learning techniques, models, and projects.
- **Datasets**: Files such as `.csv`, `.json`, etc., used in the respective day’s project or task.
- **Additional Resources**: Notes or references for better understanding of the concepts.

## Getting Started

### Prerequisites:
- Python 3.x
- Libraries: `numpy`, `pandas`, `matplotlib`, `seaborn`, `scikit-learn`, `tensorflow`, `keras`, `torch`, `xgboost`, etc.
